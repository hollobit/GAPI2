K-GAPI Δ — Agentic 시대 공공 API 개선 비교

한국 data.go.kr 및 전체 215개 공공 API 포털의 2026-04 기준선 대비 개선 여부와 Agentic 준비도를 공개 증거로 비교합니다.

K-GAPI Δ는 2026-04 K-GAPI 기준선(before_baseline) 대비 data.go.kr 게이트웨이를 포함한 전체 215개 포털을 재측정해(심층 라이브 17 + 무인증 라이트 프로브 215 + 문서·조사 기반) (1) 지적된 문제가 실제로 개선되었는지, (2) Agentic 성숙도(에이전트가 스스로 발견·인증·호출·복구할 수 있는 정도) 목표 대비 어디까지 왔는지를 비교합니다. 방법론은 증거 우선(evidence-first)입니다 — 예를 들어 일부러 잘못된 키로 호출해 HTTP 의미론(상태코드 정직성)을 검증하는 식으로, 모든 판정에 재현 가능한 증거(curl 명령어 · 응답 샘플)를 링크합니다.

개선 비교 대시보드

전체 215개 포털로 확장된 재측정 결과(심층 라이브 17 + 무인증 라이트 프로브 215 + 문서 기반). data.go.kr은 "항상 200" 문제를 개선(이제 400 반환)하고 JSON을 갖췄지만, OpenAPI·RFC7807 에러·RateLimit 헤더·CORS·헤더 인증은 미개선이고 중앙정부 공식 MCP도 부재(서울시 파일럿 1호·커뮤니티 79종만 존재) — AI 적합성 D→D(3→5). 4계층(루브릭·문제 트래커·등급 이동·준비도 히트맵), 모든 판정에 증거 링크.

이용 절차 분석

사람과 AI 에이전트가 data.go.kr에서 데이터·OpenAPI를 실제로 쓰기까지 몇 단계와 몇 번의 인간 개입이 필요한지, 에이전트는 토큰을 얼마나 추가로 태워야 하는지(검색 1페이지 ≈13.3만 토큰 실측) 정량 분석하고, 해외 사례 기반 Agent Access Layer 개선안을 제시합니다.

방법론 · 투명성

  • measured (live) — 이번 주기에 실제 HTTP 호출로 직접 재측정된 항목. 재현 가능한 curl/응답 증거가 함께 제공됩니다.
  • doc — 공식 문서·공무 자료 등 2차 자료에 근거한 판정(직접 호출로 검증되지 않음).
  • 측정불가 — 접근 차단·인증 미보유 등의 사유로 현재 주기에서는 판정할 수 없음. 평균 점수에서 제외되며 감점 사유가 아닙니다.
  • 모든 증거 샘플에서 serviceKey 등 인증키는 게시 전 마스킹됩니다.
